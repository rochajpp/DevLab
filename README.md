# 🚀 Seja Bem-vindo ao DEVLAB

Repositório destinado a estudos, experimentos, provas de conceito e testes relacionados ao desenvolvimento de software.

## 📚 Objetivo

Centralizar conteúdos de aprendizado em um único lugar, reunindo exemplos práticos, exercícios, projetos de estudo e testes de tecnologias.

Cada estudo é organizado em sua própria branch, permitindo que os conteúdos permaneçam isolados e fáceis de encontrar.

## 🌿 Estrutura

Os estudos são separados por branches nomeadas de acordo com o assunto ou tecnologia abordada.

### Exemplos

* `react_api`
* `react_nodejs`
* `node_mongodb`
* `node_authentication`
* `git`
* `docker_nginx`

> Novas branches são adicionadas conforme novos estudos são realizados.

## 🔍 Como encontrar um estudo

1. Clique no seletor de branch localizado na parte superior da página (onde normalmente aparece `main`).
2. Digite o tema desejado na busca.
3. Selecione a branch correspondente ao conteúdo que deseja acessar.

## 💻 Como clonar e acessar uma branch

Clone o repositório:

```bash
git clone <url-do-repositorio>
```

Acesse a pasta:

```bash
cd DEVLAB
```

Troque para a branch desejada:

```bash
git checkout <nome_da_branch>
```

## 🌱 Para iniciantes

Se você está começando e ainda não conhece Git e GitHub, recomendo iniciar pela branch:

```text
git
```

Nela você encontrará conteúdos introdutórios sobre:

* Git
* GitHub
* Controle de versão
* Branches
* Commits
* Fluxos básicos de trabalho

Basta pesquisar por `git` na lista de branches e acessar o conteúdo.
